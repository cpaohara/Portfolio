My version is programmed in Python using the PyGame module. Being the first big project I have done, the set-up and programming conventions are poor, with the while game in one file, and variable and function names not adhering a naming standard.

02/2026 | Artillery Defense UndergraduateJavaScript & HTML

Created during the second module of my first year at uni, Artillery Defense is a small cannon game made in the JavaScript canvas. The player controls a cannon on the left side of the screen and must shoot incoming enemies before they reach the player. These enemies have varying speeds, and health, and some can shoot back at the player. The player gains a point for every enemy destroyed, and has 4 shell types to choose from, these are:

  • Short range - A slow short range shell, for destroying enemies close to the player
  • Medium range - A regular, medium range shell, for most enemies
  • Long range - A fast long range shell, for enemies too far away for a medium shell to reach
  • Tracer - A medium range shell that doesn't damage enemies, but traces it's path in the air, to aid aiming.

The number of clouds, size and position are randomly generated each game. The clouds are also transluscent, so the shells can go behind the clouds and be somewhat visible, depending on the density of the clouds in that position
